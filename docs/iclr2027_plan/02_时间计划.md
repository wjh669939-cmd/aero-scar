纪律：C 封存认证集后不参与任何候选讨论；认证集对 A/D/E 与 agent 全程不可见。

GPU 预算核算（导师已确认算力不设限、可租卡；单 trial 30 epoch ≈ 0.75 h）：

| 项目 | 估算 | GPU 解锁后的升级 |
|---|---|---|
| 基线 seed × 3 任务（三机场）| ~12 h | seed 数 3 → **5**（增强稳定性主张，成本可忽略） |
| **Scratch vs 预训练版对照复现**（验证 T+1 异常是否在修复版代码上存在） | 视预训练成本 | 新增；tier-2 押注的前置条件 |
| 双轴 LLM discovery：2 × 20 = 40 trials | ~30 h | 全保真运行，**不做低保真筛选**（消除排名相关性风险） |
| 匹配预算随机对照：40 trials | ~30 h | 与 LLM 臂**租双卡并行**，关键路径压缩约一半 |
| （P1）matched-trial 超参搜索对照（Optuna，40 trials，同预算同 evaluator） | ~30 h | 新增可选：对齐分子论文的 AutoML 对照，直接回应"这只是调参"质疑；瓶颈是 E 的人时（约 1 天实现），不是 GPU |
| 候选确认：≤4 候选 × **5 seed** | ~15 h | seed 3 → 5 |
| tier-2 预训练候选（如异常复现成立，≤4） | 视预训练成本 | 8/26 实测单 epoch 成本后定 |
| 一次性认证（推理为主） | ~10 h | — |
| 失败与返工冗余（30%） | ~40 h | — |
| **合计** | **~170–220 h** | 双卡并行约 4–5 天，完全可行 |

**纪律：GPU 解锁买的是 seed 数、并行度和对照完备性，不买范围膨胀。** 轴数不加、trial 上限不加、认证仍只有一次；唯一新增的实验类别是 P1 超参搜索对照，且以人时为准入条件。

**验收（8/31）**：基线表 + 冻结 evaluator digest + 2 个完整 trial 产物。任一项延误 ≥2 天 → 触发**分支 C**（砍范围）。

### 阶段 2：发现与对照（9/1 – 9/9）★第二个 go/no-go

- 双轴 LLM discovery 各 20 trials 与 40 个随机对照 trial 并行；**租双卡：LLM 臂与随机臂各占一卡，纯算力压缩至约 1.5–2 天**；
- （P1）若 E 在 9/5 前完成随机对照且有余力：加 matched-trial 超参搜索对照（Optuna，40 trials，同动作预算同 evaluator），9/7 前跑完，否则放弃不追；
- A 值守闭环与失败恢复；D 管队列；B/C 只出评测数字，不参与候选讨论；
- 每轴 top-2 进 3-seed 确认（配对同 seed 比较）；
- tier-2（预训练目标干预，如阶段 0 确认可行）：≤4 候选，围绕"时距条件化对齐权重"假设（对应 Table 3 中 Scratch 在 T+1 反超预训练模型的异常），**9/6 前必须启动，否则本篇放弃 tier-2**；
- E：实验设置章节、Figure 2（数据与认证划分）、主表空模板；每日更新 trial 账本（完成数/失败数/剩余预算/当前最佳）。

**GO/NO-GO（9/9 晚）：** 是否存在候选通过 3-seed 确认、且优于随机对照最佳结果？
- 是 → 阶段 3；
- 否 → **分支 D**（诚实负结果/测量叙事），不追加预算，不延期。

### 阶段 3：冻结与一次性认证（9/10 – 9/12）

- **9/10 23:59 候选冻结**：commit、config、seed、数据 manifest 全 digest 化，Custodian 签发，此后不可修改；
- 9/11–9/12 一次性认证：{parent, 随机对照最佳, LLM 最佳} × {temporal, spatial-ZBAD, event} × 全 endpoint 网格；认证后立即重新上锁；
- **认证只执行一次。不迁移就如实报 non-transfer，禁止第二轮搜索后重测。**

### 阶段 4：写作冲刺（9/13 – 9/18）

- 9/13–15：主结果表、val→test 迁移散点图（按轴着色）、案例三则（一个 accepted、一个 rejected、一个如存在的 non-transfer）；
- 9/16–17：两轮内审——(1) claim-证据逐条对账 + 泄漏自查；(2) 模拟审稿（单数据集质疑、与分子论文差异、9 页内贡献是否突出）；
- **9/18：提交摘要**（作者名单此后锁定）。

### 阶段 5：全文（9/19 – 9/24）

只允许：表达润色、附录 lineage 与 trial 账本、匿名代码、reproducibility/AI-use/ethics 声明、数字一致性检查。不允许：改方法、改隐藏测试、改主结论。9/24 内部提交，9/25 官方截止留一天缓冲。

## 二、分支预案

### 分支 B：seed 方差吞掉效应量（8/26 触发）

论文从"发现改进"转向**"可靠性测量"**：在低信噪比运行任务上，闭环自动科研的 validation 增益有多少是 selection variance？设计不变（照跑 discovery + 随机对照 + 多 seed + 认证），但主结果变为：val→test 配对差值分布、LLM vs 随机的提案质量对比、seed 噪声与增益的量化关系。发现预算减半、分析与写作预算加倍。**该叙事的价值不依赖正结果**（详见 03 文档 §5）。

### 分支 C：基线/evaluator 延误 ≥2 天（8/31 前后触发）

按序砍：(1) 插补 endpoint 组；(2) tier-2 预训练线；(3) 分类降为纯 guardrail 不进主表；(4) Representation 轴 trial 数从 20 减到 12。冻结日 9/10 不动。

### 分支 D：无候选通过确认（9/9 触发）

转诚实负结果叙事（03 文档 §5），全部 40+40 trial 账本成为主要数据；补充分析：失败归因分类、LLM 提案与随机提案的接受率/重复率/机制合理性对比。

### 分支 E：认证不迁移（9/12 触发）

不是失败，是发现：报告 validation-only 增益 + non-transfer 签名归因（selection variance vs distribution shift，对应到我们的三环境），与分子论文的两个签名直接对话。主表照出，结论如实。

### 分支 F：全面延误（9/9 仍无基线或闭环未打通）

放弃 ICLR 2027，全量转 ICML 2027（约 2027-01 截稿），范围恢复：补 AutoML 对照、可靠性消融、tier-2、可能的第二任务。此分支由导师在 9/9 会议上拍板。

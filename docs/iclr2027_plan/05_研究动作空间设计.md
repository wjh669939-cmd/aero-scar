# 研究动作空间设计 v1.0（基于 AeroWF 模型与任务实际）

> 日期：2026-08-23
> 依据：KDD 2026 AeroWF 论文（架构、Table 1 输入变量、Table 3/4 消融证据）+ 作者答复（仓库为中间版本、模型仍有很多可改进处、超参可动）
> 原则：每个动作必须由**模型自身的证据**驱动，带机制假设与证伪条件；不是从通用清单里抄。导师的框架图只作参考。

---

## 一、设计原则

1. **证据驱动**：每个动作必须能指向 KDD 论文消融表/主表中的一个具体现象，或数据审计中的一个具体缺陷；
2. **可证伪**：登记时必须写明"在哪个 endpoint 切片上预期改善、出现什么结果算被证伪"；
3. **文件级 axis lock**：Representation 轴只许改特征/输入编码文件，Objective 轴只许改损失文件；evaluator、切分、指标、认证集全程锁定；
4. **两层成本**：tier-1 = 只动下游训练（约 0.75 GPU 时/trial）；tier-2 = 需重新预训练（成本 8/26 实测后定，且以"T+1 异常在 AeroWF† 上复现"为启用前提）；
5. **模板 + 自由提案**：下列动作作为预实现模板（也是随机对照的采样空间）；LLM 允许在文件锁范围内提出模板之外的新动作，重复性由 memory 检测。

## 二、证据锚点 → 动作映射

| KDD 论文/数据中的证据 | 机制解读 | 派生动作 |
|---|---|---|
| Table 1 脚注：**输入 METAR 天气码被简化为一个二值 flag**，而预测目标却覆盖 21 类天气 | 输入端丢弃了危险天气的语义细节，模型只能从数值通道间接推断天气类型 | R1 |
| Table 4：w/o METAR 时分类 CSI 从 49.6 崩到 34.1 | METAR 承载危险天气语义，是 CSI 的主要信息源——强化它的表示收益最大 | R1, R2 |
| METAR 逐时签发，但按静态背景**广播到全部 96 个时间步** | 报文时效性被抹掉；起报前 1 分钟和 59 分钟的 METAR 权重相同 | R3 |
| 官方指标含 Crosswind MAE，但输入风场是纬向/经向 (u,v) 分解，与跑道方向无关 | 模型必须自己学习跑道几何；显式给出跑道坐标系分量是免费的物理先验 | R4 |
| 逻辑回归对照：雾/霾少数类明显困难 | 雾的物理前兆是露点差趋近于零 + 静风，这些是现成变量的简单组合，但未作为显式特征 | R5 |
| Table 4：w/o Freq 使预测 RMSE 从 0.759 恶化到 0.865（最大单项退化） | 频域分支对长时效关键；但单一 FFT 只有全窗口分辨率，突发风与日周期混在一起 | R6 |
| **Table 3：Scratch 在 T+1 MAE 反超预训练模型（0.3030 vs 0.3086），但 T+8 与稀疏插补上预训练大幅领先** | 统一的几何对齐目标（SoftDTW+谱一致性）可能对短时效瞬态负迁移：把"形状相似"的场景拉近，抹掉了战术尺度的瞬变差异 | O4, O5（tier-2 旗舰） |
| 预训练随机/因果遮挡各 50%（Bernoulli p=0.5） | 因果遮挡对应预测任务、随机遮挡对应插补任务；50/50 是未经论证的默认值 | O6 |
| 分类用统一 Focal Loss，长尾未按类校准 | 雾/霾等少数类的 α/γ 未按频率分层 | O3 |
| 三个预测时效共用一个损失 | T+1 与 T+8 的误差量纲与业务价值不同，统一 MSE 隐含地按方差大小分配容量 | O1, O2 |

## 三、Representation 轴（tier-1，只改特征/输入编码文件）

| ID | 动作 | 机制假设 | 预期作用切片 | 证伪条件（示例，登记时定量化） |
|---|---|---|---|---|
| R1 | **METAR 天气码结构化嵌入**：把二值 significant-weather flag 还原为分组类别嵌入（降水/视程障碍/对流/无） | 输入端恢复危险天气语义，分类头不再从数值通道间接猜天气类型 | 分类 CSI、雾/霾 F1；次要：极端事件切片的预测误差 | ≥2 机场上分类 CSI 无改善；或预测主网格恶化超容差 |
| R2 | 露点差 + 气压 3h 趋势 + 阵风-平均风差 | 雾（T−Td→0）、锋面过境（气压趋势）、湍流（阵风差）的教科书前兆量 | 雾/霾类 F1、T+4/T+8 预测 | 少数类 F1 不升；主网格恶化 |
| R3 | **METAR 报文时效特征**（age-of-report：距签发的分钟数） | 静态广播抹掉时效；显式时效让模型学会对旧报文降权 | 全预测网格，尤其 METAR 更新间隙的样本切片 | 全网格无改善 |
| R4 | **跑道坐标系风分解**：按每条跑道磁向计算顺风/侧风/阵风侧风分量（需数据侧建跑道方位表） | Crosswind 是官方指标与业务量；显式几何先验免去模型自学坐标旋转 | Crosswind MAE、危险天气 CSI | Crosswind MAE 在 ≥2 机场无改善 |
| R5 | 风向周期编码（sin/cos）与风速-风向解耦 | u/v 分解在低风速下方向信息被幅值淹没 | 低风速切片、T+1 | 目标切片无改善 |
| R6 | 多尺度时间差分特征（1 步/4 步差分、滚动方差） | 频域分支只有全窗口 FFT 分辨率；显式差分补充战术尺度瞬变 | T+1 预测、突发风切片 | T+1 无改善或长时效明显恶化 |

## 四、Objective 轴

### tier-1（只改下游损失文件）

| ID | 动作 | 机制假设 | 预期作用切片 | 证伪条件 |
|---|---|---|---|---|
| O1 | 时效加权 MSE（T+1/T+4/T+8 权重可调，含反向配置） | 统一 MSE 隐含按方差分配容量，短时效被牺牲 | 按权重方向的对应时效 | 目标时效无改善或其余时效超容差恶化 |
| O2 | 危险天气事件加权回归损失（权重仅由训练集标签定义） | 平均误差被平静天气主导，业务关键样本欠拟合 | 极端事件切片的预测误差、CSI guardrail | 事件切片无改善或整体 MAE 超容差 |
| O3 | 分类 Focal Loss 按类频率分层的 α/γ | 统一 focal 参数对 21 类长尾欠校准 | 雾/霾等少数类 F1、Macro-F1 | 少数类不升或多数类崩 |

### tier-2（需重新预训练；启用前提 = T+1 异常在 AeroWF† 上复现）

| ID | 动作 | 机制假设 | 预期作用切片 | 证伪条件 |
|---|---|---|---|---|
| O4 | **时距条件化对齐权重**：λ_align 随因果遮挡的预测距离衰减（短时效重建为主、长时效对齐为主） | 几何对齐对长程结构有益、对短时瞬态负迁移；按尺度分工可两全 | T+1 MAE 追平/反超 Scratch，同时保住 T+8 与稀疏插补优势 | T+1 仍落后 Scratch；或 T+8/插补优势丢失 |
| O5 | 对齐先验作用于降采样序列（DTW/谱匹配只约束粗尺度形状，不约束逐步瞬变） | 同 O4 的另一实现路径：从约束对象而非权重入手 | 同 O4 | 同 O4 |
| O6 | 预训练遮挡配比 p（随机:因果 = 50:50 → 30:70 等） | 因果遮挡对应预测、随机遮挡对应插补；配比应反映下游任务组合而非默认 0.5 | 预测网格 vs 插补网格的此消彼长关系 | 预测无改善；或插补退化超容差 |

## 五、明确不做（写入动作空间负清单）

- ~~Model 轴~~ → **状态变更：升级为条件性第三轴，见 §九 修订提案（8/27 决策）**；
- **Data 轴**（外部数据获取）：需要污染过滤器体系，本篇不做；
- 纯训练超参扫描（lr/batch/epoch）：不属于任何轴——这正是 P1 超参搜索对照（Optuna）的领地，用来证明轴动作的超额价值；
- 同时改两个轴的复合动作：违反 axis lock，validator 直接拒绝。

## 七、随机对照与超参对照的采样空间

- **随机对照臂**：从 R1–R6、O1–O3 模板及其参数范围中均匀合法采样（不含 LLM 生成的自由动作），同 trial 数、同 evaluator、同接受规则——回答"LLM 的机制推理是否优于盲抽同一动作空间"；
- **（P1）超参对照臂**：Optuna 在冻结的训练超参空间（lr、weight decay、scheduler、focal 默认参数）内搜索，同预算——回答"轴动作是否超越纯调参"。

## 八·五、修订提案 v1.1：受约束的 Model 轴（待 8/27 决策）

### 动机（为什么重新考虑）

1. 分子论文中**唯一**让 LLM 明确超越 matched AutoML 的是 model-code 轴（Polaris：LLM val +0.066 → test +0.042，AutoML 仅 +0.006）——"改代码超越调参"的全部证据来自模型轴；
2. 本方案 R 轴与 O-tier1 动作大多可参数化，随机/Optuna 臂原则上可采样到；若 tier-2 因"T+1 异常不复现"而取消，两轴方案将只剩可参数化动作，"高级调参"质疑难以回应；
3. KDD 作者明确表示模型仍有很多可改进处。

### 反混淆约束（三条全部强制，validator 执法）

1. **参数量预算**：|Δparams| ≤ 基线 4.2M 的 5%，preflight 自动计数，超限拒绝训练；
2. **训练预算冻结**：epoch/batch/优化器/调度与 parent 完全相同；
3. **接口与冒烟**：输入输出 shape 不变；前向+反向 smoke test 通过后才允许全量训练。

文件锁：只开放模型模块文件（融合、注入、聚合器），训练循环/特征/损失文件均锁定。

### 预注册动作锚点（M 轴，tier-1）

| ID | 动作 | 证据锚点 | 机制假设 | 证伪条件 |
|---|---|---|---|---|
| M1 | 时距条件化融合门（gate 以预测距离为条件） | w/o Freq 使长时效 RMSE 最大恶化，而门控融合对时效不敏感 | 短时效应偏向时域流、长时效偏向频域流，静态门是折衷 | 任一时效无改善或整体恶化超容差 |
| M2 | METAR 注入机制：静态广播 → 报文时效衰减注入 | METAR 逐时签发却广播到 96 步（与 R3 同源证据，作用在机制而非特征层） | 旧报文应随时效衰减权重 | 全网格无改善 |
| M3 | 跨跑道聚合器变体（如轻量跑道间注意力，参数预算内） | w/o Hier 显著伤插补；Mean/Max Pool 伤 Crosswind 与 CSI | 跑道间关联的显式建模优于均值式聚合 | 插补/Crosswind 切片无改善 |

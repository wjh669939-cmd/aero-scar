# 自由提案（free proposal）设计方案 v0.1

> 状态：**方案稿，未实施**。等 trial 3 结果后由 A 拍板落地；落地时刻仍在任何候选
> 产生之前，属预注册修正。
> 背景：8/27 复盘发现 LLM 臂前 4 个提案全部选择模板动作（阻力最小路径），若持续
> 如此，"LLM 作为科研策略"退化为结构化搜索（AutoML 等价），论文差异化主张失据。
> 分子论文为纯自由模式（轴锁内任意代码）；我们采用"模板保底 + 自由保上限"混合模式，
> 本方案定义自由层的触发、约束、记账与评价规则。

---

## 一、四个设计问题与对应规则

### 规则 1：触发——什么时候必须自由

- **强制触发**：同一轴**连续 2 个模板 trial 被裁决 refuted**（verdict_rule_v1）后，
  该轴下一个 LLM trial 必须为自由提案（`action_id` 以 `free-` 开头）；
- **自愿触发**：任何时候 LLM 可自选自由提案，无需理由审批；
- **豁免**：若该轴 active 模板中仍有**从未尝试过**的动作，强制触发顺延一发（先穷举
  机制面，再放开自由）。
- 触发状态由驱动从 lineage 自动计算，不留人工裁量。

### 规则 2：真实性——防"假自由"

自由提案必须比模板提案多交一个字段：

- `non_expressibility`（≥30 字）：说明该机制**为什么不能被现有模板 + 参数表达**。
  该字段入 lineage，供事后审计"LLM 是否真的超出人类预设动作空间"。
- 驱动做形式检查：若提案机制与某模板动作实质等价（同一目标文件 + 同一机制关键词），
  按 `proposal_rejected` 记录并要求重提（至多 2 次）。

### 规则 3：记账——三类别分离，保护两臂对照

统计口径（写入 decision_policy 备注，认证与论文报告同口径）：

| 类别 | 空间 | 回答的问题 |
|---|---|---|
| 随机臂 | 模板 + param_space 均匀采样 | 结构化搜索基线 |
| LLM 模板臂 | 同上，LLM 选择 | LLM 选得比随机好吗？（配对对照） |
| LLM 自由臂 | 轴锁内任意合法代码 | LLM 能否超出预设空间？（独立报告） |

- 两臂对照（LLM vs 随机）**只在模板空间内比较**；自由提案不进对照，单列；
- 自由提案的成败**如实全量报告**（含 smoke_rejected / refuted），不做筛选性展示；
- 预算记账：自由 trial 与模板 trial 同池扣减（GPU 小时口径），比例作为报告统计量。

### 规则 4：平等——评价标准零特权

自由提案与模板提案共用全部规则，无一例外：同一轴锁、同一冒烟闸门（+1 次修复轮）、
同一筛选线（配对改善 ≥0.0005）、同一 3-seed 确认、同一 guardrail、同一隐藏认证。
"自由"仅存在于提案空间，不存在于评价标准。

## 二、实施清单（落地时执行，预计 0.5–1 小时）

1. **提示词** `prompts/llm_proposal.md` v0.2 → v0.3：
   - 增加自由提案的显式说明与 `non_expressibility` 字段要求；
   - 强制触发时，注入一行状态提示："该轴模板动作已连续证伪，本轮必须提出
     模板空间之外的机制（free-<slug>）"；
2. **驱动** `discovery_runner.py`：
   - lineage 扫描函数：计算各轴连续 refuted 计数与未试模板集合，得出本轮是否强制自由；
   - 提案解析后校验：强制轮拒绝模板 `action_id`；自由提案校验 `non_expressibility`；
3. **解析器** `proposal_parser.py`：接受可选 `non_expressibility` 字段并透传至 trial 记录
   （schema 的 additionalProperties 已允许，无需改冻结 schema）；
4. **decision_policy 备注**：写入三类别统计口径（不动阈值，不动任何判定规则）；
5. **单测**：触发计算（连续 refuted / 豁免 / 复位）、假自由拦截、字段校验，约 6-8 例。

## 三、风险与对策

| 风险 | 对策 |
|---|---|
| 自由提案代码死亡率高，烧预算 | 冒烟闸门已把损耗压到秒级；修复轮失败即 smoke_rejected，不进训练 |
| 强制自由轮恰逢模型状态差，产出垃圾机制 | 垃圾机制会被筛选线和裁决规则如实拒绝，成本可控（一发 2.8h 上限） |
| 三类别切分后各类样本量更小 | 如实报告置信区间；论文叙事按证据强度分层，不夸大 |
| 触发规则事后被质疑是"看结果调整" | 本方案在首个候选出现前落地并留痕（本文档 + git 归档 + campaign_state） |

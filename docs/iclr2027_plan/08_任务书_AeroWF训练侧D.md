## 〇、红线纪律

1. 任何训练/评测代码路径不得触碰认证数据（三机场 test 尾部、ZBAD、event 清单）——路径禁访 token 由 C 提供，写进你的运行脚本断言；
2. 基线调参只允许在**冻结校准预算内**进行且逐次留痕（`tuning_log.jsonl`：改了什么、为什么、结果）；校准预算用完即冻结，此后基线不再动；
3. 固定 seed 清单全项目统一：**{42, 2027, 3407, 5519, 7919}**（前 3 个用于筛选期，5 个用于 parent 与最终确认）；
4. 每次运行必须登记：commit、config digest、数据 manifest digest、seed、wall-clock、显存峰值、GPU 型号。

## 一、任务清单

### D1｜30 epoch Scratch 正式跑 + seed 方差测量（8/24–8/26）★全计划第一个 go/no-go 的证据来源

- 在 B 的新切分（三机场 + purge gap）就绪前，可先用现有四机场切分跑**方差预估**（结论标注"旧切分"），新切分就绪后重跑正式版；
- 3–5 seed × 30 epoch Scratch（插补任务已就绪，先跑它）；
- 产出"效应量 vs 噪声"报告：各 endpoint 的 seed 间标准差、配对差值的波动范围——**8/26 晚全组据此判定走主线还是分支 B**；
- 注意用配对比较口径（同 seed 的 parent/candidate 差值），这比裸方差更能反映真实噪声下限。

### D2｜预测与分类任务头复现（8/25–8/27）

- 目前只有插补在跑；补齐 wind 预测（T+1/T+4/T+8）与 21 类→3 级分类头（Focal Loss 按论文口径）；
- 与 C 的 evaluator 草案联调：三任务都能输出 endpoint 网格指标；
- 遮挡协议按作者澄清执行：预训练 40%、下游 25%，写进配置。

### D3｜AeroWF† 正式基线（8/27–8/31）

- 三机场新切分上：**5 seed × 3 任务** Scratch parent；
- 校准预算（建议：≤10 次配置尝试，用于 lr/收敛性等基本健康度，不做架构或损失改动）——用完即冻结，全部尝试进 `tuning_log.jsonl`；
- 同一 evaluator 跑 Persistence、逻辑回归、多数类参照入表；
- 验收：基线显著优于简单参照；均值 ± 标准差 + CI 表落盘；checkpoint + predictions 全部 digest 化。

### D4｜Scratch vs 预训练对照（8/27–9/2，前提：B2 确认预训练数据可用）

- 复现预训练（40% 遮挡、100 epoch 或按 B2 实测成本调整并留痕）→ 微调 → 与 Scratch 同 seed 配对比较；
- **核心问题只有一个：Table 3 的"Scratch 在 T+1 MAE 反超预训练"在修复版代码上是否复现？**
- 结论书面化 → 决定 tier-2（O4/O5/O6）是否启用；
- 若预训练单次成本 >8 GPU 时，先与 A 商定是否租更大卡，不自行缩预算。

### D5｜Discovery 期间的运行值守（9/1–9/9）

- 租卡方案：LLM 臂与随机臂各占一卡并行（P1 Optuna 臂如启用再加一卡）；
- 职责：trial 队列调度、失败重试（新 attempt_id，不覆盖旧记录，GPU 时间照记账）、每日账本（完成/失败/剩余预算/当前最佳）；
- harness 报错时的分工：执行环境问题你处理，闭环逻辑问题交 A——判不清就直接找 A，不要自行改 harness 代码；
- 从本阶段起你兼任 harness 二线：跟 A 过一遍 T1–T8 的产物文档（对应 04 文档 R7 单点风险）。

### D6｜候选确认与冻结支持（9/9–9/10）

- 各臂 top 候选 × **5 seed** 配对确认（同 seed 的 parent/candidate 对比）；
- 9/10 冻结日：向 A 提交每个冻结候选的 checkpoint/config/predictions digest 清单，供 Custodian 核验；
- 冻结后你手上不再有任何"可以再改一下"的入口——有问题走分支预案，不走私改。

## 三、失败处置

- D1 方差结论恶劣（噪声 ≥ 效应量）：不是你的失败，是 8/26 全组决策点的输入——如实报告；
- D2 分类头复现严重超时：分类降级为纯 guardrail（不进主表），先保预测网格；
- D4 预训练复现失败或异常不复现：tier-2 取消，如实记录（这本身可写进论文的 reproducibility 讨论）；
- 租卡环境与 3090 结果不一致（同 seed 同 config 指标漂移超过噪声）：立即上报，认证环境必须与确认环境同型号。

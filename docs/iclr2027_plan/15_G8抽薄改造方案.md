# G-8 抽薄改造方案（trial_features / trial_objective 拆分）

> v1.0，2026-08-27。A 出方案，D 执行。目的：让文件级 axis-lock 在下游脚本上成立。
> 背景见 `axis_lock_v1_draft.json` 的 `known_risk_file_mixing`；代码位置以 D 的 CODE_MAP.md 为准。

## 一、问题

`aerowf_forecast_train_v2.py` 与 `aerowf_classification_train_v2.py` 同一文件混含三类东西：

| 内容 | 归属 | discovery 中能否被改 |
|---|---|---|
| 输入/特征构造（`AirportForecastDataset` 特征段、`AllowedContextEncoder`） | **R 轴对象** | 允许（R 轴 trial） |
| 损失（`masked_mse`、`balanced_class_weights` + `cross_entropy` 组装） | **O 轴对象** | 允许（O-tier1 trial） |
| 训练循环 + optimizer（`train_epoch`/`evaluate`/`main`） | 永久锁定 | 禁止 |

文件级锁只能"整文件允许或禁止"，混在一起就没法锁。方案：把 R/O 对象各抽成独立模块，主脚本 import；抽完之后两个主脚本整体进入锁定名单。

## 二、目标布局（与 axis_lock 已冻结的 allow 路径一致，勿改名）

```
aerowf_downstream_v2/src/

├── trial_objective.py     # O-tier1 轴唯一可写文件
├── aerowf_forecast_train_v2.py        # 抽薄后整文件锁定
└── aerowf_classification_train_v2.py  # 抽薄后整文件锁定
```

## 三、trial_features.py 抽什么

从两个下游脚本移入（**移动，不是复制**，原文件只留 import）：

1. `AirportForecastDataset` 中的**特征构造段**：窗口→模型输入张量的组装逻辑（外生变量选择、拼接、编码方式）。时间戳对齐与 T+1/4/8 目标生成**不抽**——那是 contract 语义，留在锁定文件里；
2. `AllowedContextEncoder`（分类安全外生编码，整类移入）；
3. `AirportClassificationDataset` 的特征构造段（同上，标签映射 `map_labels` **不抽**，属 contract）。

推荐接口（D 可按实际代码微调，但函数签名要在 G-1 联调前定稿，因为要写进 LLM 提示词合同）：

```python
# trial_features.py —— R 轴 trial 只能改这个文件
def build_forecast_inputs(window_df, runway_arr, exo_cat, exo_cont, *, norm_stats) -> dict[str, Tensor]: ...
class AllowedContextEncoder(nn.Module): ...   # 分类外生编码
def build_classification_inputs(...) -> dict[str, Tensor]: ...

# 防泄漏断言（锁定文件里调用，trial 改不掉）：
FORBIDDEN_INPUT_COLUMNS = ("weather_code_id", "weather_label", "significant_wx")
```

**红线（写死在锁定主脚本里，不在 trial_features.py 里）**：
- 主脚本在构造 Dataset 后断言输入不含 `FORBIDDEN_INPUT_COLUMNS`（分类泄漏检查保持现有逻辑位置不动）；
- 目标生成（label/target 列的抽取）保持在主脚本——trial 不能改预测什么，只能改怎么表示输入。

## 四、trial_objective.py 抽什么

1. `masked_mse`（forecast 损失，整函数移入）；
2. `balanced_class_weights` + cross_entropy 组装段，包成一个函数：

```python
# trial_objective.py —— O-tier1 trial 只能改这个文件
def forecast_loss(prediction, target, node_mask) -> Tensor: ...       # 现 = masked_mse
def classification_loss(logits, label, *, class_weights) -> Tensor: ...  # 现 = weighted CE + ignore_index
def compute_class_weights(train_label_counts) -> Tensor: ...          # 现 = balanced
```

**不抽**：`IGNORE_INDEX` 常量语义、`train_label_counts` 的"只用训练集统计"调用位置——统计来源留在锁定主脚本，trial 只能改权重怎么算、损失怎么组合，不能改统计喂的是哪个集合。

## 六、注意事项

- **随机流风险**：如果特征构造段里有 `torch.rand`/`np.random` 调用，移动文件不改变调用顺序就不影响随机流；不要顺手"清理"任何代码，这一轮只许移动；
- **import 环**：trial_objective.py 不 import trial_features.py，两文件都不 import 主脚本；
- 预训练侧（`FrozenAeroWFDataset`）本轮**不抽**——tier-2 O 轴（DEC-002）激活后再说，预训练损失的文件划分已在 axis_lock 的 objective_tier2 里定义；
- 抽薄验收前 R/O 轴在 axis_lock 里虽标 active，但 A 侧不会放行任何 trial（工程上 discovery 尚未开跑，无实际风险）。

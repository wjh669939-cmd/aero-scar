## 4. 私有配置 JSON 与环境变量

评测器**只认**环境变量（源码：`AEROWF_EVALUATOR_PRIVATE_CONFIG`）。未设置时输出 `failed` / `未安装 C 私有配置`。

写入（login shell 永久生效，例如 `/root/.bashrc` 或独立 `evaluator.env`，由 C 选定一处并告知 A）：

```bash
export AEROWF_EVALUATOR_PRIVATE_CONFIG=/root/autodl-tmp/c_evaluator_private/private_config.json
```

`private_config.json` 必须含评测器已读取的键（路径改为 C 实际落盘路径）：

```json
{
  "val_data_root": "/root/autodl-tmp/c_evaluator_private/val_data",
  "mask_root": "/root/autodl-tmp/c_evaluator_private/masks",
  "split_manifest": "/root/autodl-tmp/c_evaluator_private/split_manifest.json",
  "normalization_stats": "/root/autodl-tmp/c_evaluator_private/normalization_stats.json"
}
```

不要把该 JSON 拷进 git、CLH 仓库或 `clh_deploy` 公开树。

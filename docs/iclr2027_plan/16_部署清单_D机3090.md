## 二、D 机上的环境步骤

1. **不动 AeroWF 训练环境**（torch2.5.1/cu124 那套 venv 原样保留）；CLH 用**独立 venv**（CLH 自身不需要 torch 跑训练——训练在子进程里用 D 的环境）：

```bash
python3 -m venv ~/clh_venv
~/clh_venv/bin/pip install -e ~/clh   # 按 CLH 的 pyproject/requirements
```

2. 执行器配置指向 D 的真实路径（`PipelineConfig`）：
   - `pipeline_script = /root/autodl-tmp/aerowf_downstream_v2/src/aerowf_full_pipeline_v2.py`
   - `workdir = /root/autodl-tmp/aerowf_baseline/AeroWF`（HANDOFF §4 强制）
   - `output_root_base = /root/autodl-tmp/aerowf_downstream_v2/results/harness/`
   - `python_bin` = **D 训练 venv 的 python**（不是 clh_venv）
3. axis_lock 的 `hidden_data_guard` 追加 C 私有配置目录的路径 token（C 部署后提供目录名）。

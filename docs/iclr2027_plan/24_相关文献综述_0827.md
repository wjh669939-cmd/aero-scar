## 一、自动科研主线（我们所在的赛道）

| 文献 | 做了什么 | 与我们的关系 |
|---|---|---|
| ★ **AI Scientist**（Lu et al., Sakana，arXiv 2024 → **Nature 2026**） | 首个端到端全自动科研管线（想法→实验→写稿→自评审）；Nature 版正式化 | 赛道开创者，必引。差异：它面向"能否产出论文"，我们面向"产出的改进是否可信可迁移"——它没有隐藏认证、没有预注册门槛 |
| ★ **AI Scientist-v2**（arXiv 2504.08066） | 去模板化 + 实验管理 agent 的渐进树搜索（BFTS）；首篇过同行评审的全 AI workshop 论文 | 树搜索思路与我们的父子链谱系可对话；其"最佳分支选择"仍以验证集为准——正是我们攻击的 selection variance 问题 |
| ★ **Agent Laboratory**（Schmidgall et al., EMNLP Findings 2025） | 文献综述→实验→报告三阶段；mle-solver 用 LLM reward model 给代码打分（0-1） | 关键对照点：**它用 LLM 当裁判，我们用冻结评测器当裁判**。LLM-as-judge 的校准问题（见 HindSight）是我们设计的直接依据 |
| ★ **DOLPHIN**（Yuan et al., ACL 2025，组员推荐） | 闭环三段：文献排序引导想法生成→回溯引导调试→结果反馈下轮；改进率随轮次上升（2/7→4/8） | 最近邻工作，详见 §审计。借：回溯引导修复、想法独立性过滤、每轮改进率报告口径。差异：无隐藏认证/无种子方差/无单轴归因/无随机对照 |
| ★ **分子闭环论文**（我们的方法学锚点，Closed-loop Auto Research） | 单轴干预 + 谱系 + 一次性隐藏认证；实证 val→test 缩水（模型轴 0.041→0.003，数据轴 +0.022→−0.019） | 我们是它在真实气象领域的延伸 + 混合动作空间（模板+自由）+ 随机对照臂 + 预注册决策规则四项增量 |
| **HEP**（arXiv 2607.09195，材料科学） | 假设-测试-证据-信念作为显式可审计操作的 harness | 与我们的 lineage + verdict 思路同构，可引证"可审计性"是共识方向 |
| **LLM-AutoSciLab**（arXiv 2605.24043） | 假设条件化的主动实验设计：选"竞争机制分歧最大"的实验点 | 有价值的延伸方向：我们筛选期动作选择目前不做信息量优化，后续 campaign 可借"机制分歧最大化"排序 |
| **DiscoPER**（arXiv 2607.01131） | 迭代元反思：Reflect 模块分析已接受/拒绝的 claim，指导下轮探索；假设支持率 72.7% | 它的 Reflect ≈ 我们计划的"证据表随谱系进化"；其 held-out validation 仅是留出集，非锁定认证 |

## 二、基准与能力评估（"agent 到底行不行"的证据）

| 文献 | 做了什么 | 与我们的关系 |
|---|---|---|
| ★ **MLE-bench**（OpenAI，arXiv 2410.07095） | 75 个 Kaggle 任务测 ML 工程能力；o1-preview+AIDE 仅 16.9% 拿牌 | 引证"LLM 实验执行能力有限"——支撑我们的冒烟闸门与模板保底设计 |
| **RE-Bench**（METR，ICML 2025） | 7 个开放研究工程环境，61 位人类专家对照；2h 预算 AI 领先，32h 人类反超 2× | 引证"长周期科研 agent 不稳定"（替换早前引用的 ResearchGym 印象性结论更硬） |
| **ScienceAgentBench**（arXiv 2410.05080） | 102 个真实论文提取的数据驱动发现任务；最好 agent 独立解 32.4% | 同上，且其"多轮人工验证任务"方法可引证我们人工验收 gate 的必要性 |
| **ResearchClawBench**（arXiv 2606.07591） | 40 个真实论文复现任务，隐藏目标论文；最强 agent 均分 21.5/100，失败集中在"实验协议不匹配、证据不匹配" | 失败模式分类与我们的 lineage 事件分类（proposal/codegen/smoke_rejected/failed）可对照 |

## 三、LLM 想法生成的能力边界（支撑我们"执行验证"立场的社会学证据）

| 文献 | 做了什么 | 与我们的关系 |
|---|---|---|
| ★ **Si et al. 2024**（arXiv 2409.04109，100+ NLP 研究者盲评） | LLM 想法新颖性显著高于人类专家（p<0.05），可行性略弱 | 引证"LLM 有提出新机制的潜力"——自由提案层的依据 |
| ★ **Ideation-Execution Gap**（arXiv 2506.20803，43 人执行研究） | **执行后 LLM 想法得分大幅下滑、排名反转**；纸面新颖 ≠ 落地有效 | 我们整个"真实训练 + 独立评测 + 隐藏认证"设计的最强外部理由：想法必须过执行检验 |
| **HindSight**（arXiv 2603.15164） | 用未来发表文献做时间切分评估；LLM-as-judge 与真实影响不相关，"更新颖"与落地负相关 | 直接支撑"评测器必须是真实实验而非 LLM 打分"（与 Agent Laboratory 的 reward model 形成对照） |

## DOLPHIN 严格审计（组员推荐文献的专门评估）

**可信的部分**：闭环反馈提升想法质量的证据链完整（Tab.6 每轮改进率上升 + 有效想法不重复）；
回溯引导调试的消融干净（Tab.5，7/15 vs 4/15）；任务属性过滤论文的消融合理（新颖率 8/20→19/20）。

**要谨慎的部分**：
1. **改进的显著性未检验**：+0.6%~1.1% 的提升无种子方差、无置信区间（我们的噪声底
   0.00023 换算到它的场景，这些提升可能过筛也可能不过——它没做这个检验）；
2. **选择与报告同集**：Max Improvement 是在同一测试集上挑的最大值——正是分子论文
   证明会缩水的 selection variance；40 个想法选 5-6 个报告，多重比较未校正；
3. **基准可能污染**：ModelNet40/CIFAR-100/SST-2 均在 LLM 预训练语料覆盖范围内，
   "新想法"可能是记忆的文献方法（MLE-bench 有专门的污染分析，DOLPHIN 没有）；
4. **无泄漏治理**：标准基准无 issue-time/事件分组问题，但也意味着其结论不能外推到
   真实领域数据。

**大胆延伸（我们能做而它没做的）**：把它的"每轮改进率"曲线画在**隐藏认证后**的
结果上——"经认证的每轮改进率"是一个全新的、更硬的闭环有效性指标；此外其反馈只有
"结果摘要"，我们的反馈带裁决（supported/refuted）+ 配对效应量 + guardrail 状态，
信息密度更高，值得作为消融点（反馈信息量 vs 迭代质量）。

## 对论文叙事的三点直接影响

1. **Related Work 有了完整的三角**：端到端产稿线（AI Scientist/Agent Lab）证明"能跑"、
   能力边界线（Ideation-Execution Gap/MLE-bench）证明"跑得不可靠"、我们+分子论文
   回答"怎么跑得可信"——递进关系清晰；
2. **"不就是 AutoML"有了学术回应**：Agentic NAS 明确指出 LLM 在搜索中的分工是
   未解问题，我们的三类别记账（随机/模板/自由）就是对这个问题的受控回答；
3. **评测器立场有了外部证据**：HindSight（LLM 判断与真实影响不相关）+ Agent Laboratory
   （用 LLM reward model）形成天然对照组，支撑我们"真实实验 + 冻结评测器"的选择。
